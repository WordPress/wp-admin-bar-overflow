## Affiliation disclosure

Both initial maintainers work at Automattic, the company that builds WordPress.com and contributes substantially to WordPress core. The plugin was incubated there before being published in the open. The repo now lives under the `WordPress` GitHub org so anyone in the WordPress community can contribute on equal footing.

Decisions are made on the merits in public threads (Issues and PR review). No private decision-making channel takes precedence over public discussion. Where a decision needs a tie-breaker, the engineering lead has the final call on engineering matters and the design lead on design matters; in both cases the rationale is documented in the relevant Issue or PR.

## How to reach us

- **Public**: GitHub Issues and PRs on this repo.

## Project governance for non-maintainer decisions

For decisions that affect the project's posture but not its day-to-day code:

- **API stability promises**: discussed in an upstream Make/Core post and a public GitHub thread. Lock at v1.0.
- **Submission to wp.org plugin directory**: maintainer decision after community signal stabilizes (target v0.3.x).
- **Trademark / branding / slug changes**: requires WordPress Foundation alignment if it touches WP-trademarked terms.
- **Repository transfer to the WordPress GitHub org**: complete.
